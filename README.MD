# Учебная практика

Проект позволяющий постить и комментировать посты, реализованный на React.

## Демонстрация

Ссылка: https://v-loginov.github.io/dist/

## Установка и запуск

```bash
cd src3b-main
npm install
npm run dev
```

## Сборка проекта

```bash
cd src3b-main
npm install
npm run build
```
